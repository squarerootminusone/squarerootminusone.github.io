A control dataset for non-local transition structure

June 2026 · code and write-up

A gridworld with walls and wormholes, built as a control dataset for the original DQN result. The question it isolates is narrow: does a convolutional value predictor learn that two distant cells are one step apart, or does it fall back on spatial proximity in the image?

The experiment trains a small CNN value predictor on maps with small wormhole gaps and tests on large ones, against naive distance baselines and against a wormhole-ablated control input. It then repeats the whole thing on harder maps with randomised positions and decoy wormholes, so that a model cannot pass by memorising layout.

Design

  • Gridworld with walls and wormholes, ASCII rendering, BFS ground-truth distances
  • Dataset swept over map size and wormhole separation, generated deterministically
  • Train on small gaps, test on large gaps — the split is what makes proximity shortcuts fail
  • Wormhole-ablation control input isolates the contribution of the non-local structure
  • Two regimes: original maps, and harder maps with randomised positions and decoy wormholes
